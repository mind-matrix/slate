# Slate 2026.11.13

- This release needs a fresh image: the device user is now `slate`, and Slate's shell has become the display server. Devices on older versions are asked to flash the new image instead of updating.
- Built-in apps: Marvin, Ava and other apps install from their own signed releases, update separately from Slate, and get only the permissions Slate grants them. Settings › Apps lists them, and apps with screens get a desktop tile.
- Apps can show full-screen windows with Back and Home in the status bar, and voice captions over other screens.
- New Voice assistant setting: choose Marvin, Ava or no assistant. Only the selected assistant can use the microphone and speaker, and a badge in the status bar shows when it is listening.
- Apps can keep secrets in Slate's encrypted key store.
- Bluetooth headsets: the microphone now works, switching to call quality only while it is in use, and headsets are labelled as headsets.
- Software update lists app updates next to Slate's own.
- The touchscreen now comes up reliably at boot.
